# Aurora Systems Lab - shared code archive

This repository collects the code releases maintained by the Aurora Systems Lab.
Each sub-project is a self-contained directory with its own README. The README of
a sub-project states whether the release is actually available or still pending;
that statement is authoritative.

## Sub-projects

- `spectral_graph_sketching/` - Spectral Graph Sketching for Streaming Anomaly Detection
- `queue_aware_batching/` - Queue-Aware Batching for Latency-Critical Model Serving
- `counterfactual_curriculum/` - Counterfactual Curriculum Generation for Low-Resource Parsing
- `harmonic_tokenizer_utils/` - utilities for audio harmonic analysis
- `calibrated_retrieval_fusion/` - Calibrated Retrieval Fusion for Multi-Hop Question Answering
